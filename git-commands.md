## Commande pour cloner un repository
git clone {lien_vers_la_repo}

## Commandes pour push 
git add [.] (pour tout push) ou [{nom_fichier}] (pour push seulement certains fichiers)
git commit -m main
git push

## Commandes pour pull
git pull

## Commandes pour les branches
Lister les branches locales : git branch
Créer une nouvelle branche : git branch <nom_de_la_branche>
Changer de branche : git switch <nom_de_la_branche> (ou git checkout <nom_de_la_branche>)
